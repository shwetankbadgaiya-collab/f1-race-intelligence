# F1 Race Intelligence — Data Sources & Schema

## Overview

This directory contains the data layer for the F1 Race Intelligence Dashboard.
Data originates from the **Ergast Motor Racing Database**, now maintained as the
**Jolpica-F1 API** (`https://api.jolpi.ca/ergast/f1/`). Ergast is the
canonical, community-standard dataset for Formula 1 statistics spanning every
season from 1950 to the present.

---

## Data Sources

| Source | URL | Notes |
|--------|-----|-------|
| Jolpica-F1 API | `https://api.jolpi.ca/ergast/f1/` | Drop-in replacement for the retired Ergast API |
| Ergast CSV Dumps | (historical, archived) | Flat-file database dumps used for bulk import |
| Demo Generator | `scripts/ingest_data.py` | Generates realistic sample data when no CSV/API data is available |

> **Attribution**: All Formula 1 data is sourced from the Ergast Motor Racing
> Database. This project uses the data for educational and analytical purposes.

## Schema

The SQLite database (`f1_data.db`) mirrors the Ergast relational schema.

### Tables

| Table | Primary Key | Description |
|-------|-------------|-------------|
| `seasons` | `year` | F1 season years and Wikipedia URLs |
| `circuits` | `circuitId` | Circuits with name, location, country, lat/lng, altitude |
| `constructors` | `constructorId` | Teams / constructors |
| `drivers` | `driverId` | Drivers with code, number, name, DOB, nationality |
| `status` | `statusId` | Race finish status codes (Finished, DNF reasons, etc.) |
| `races` | `raceId` | Individual race events with date, time, round, circuit FK |
| `results` | `resultId` | Race results: position, points, grid, laps, time, status FK |
| `qualifying` | `qualifyId` | Qualifying session results (Q1, Q2, Q3 times) |
| `driver_standings` | `driverStandingsId` | Cumulative driver championship standings per race |
| `constructor_standings` | `constructorStandingsId` | Cumulative constructor championship standings per race |
| `pit_stops` | (`raceId`, `driverId`, `stop`) | Pit-stop data (lap, time, duration) |
| `lap_times` | (`raceId`, `driverId`, `lap`) | Per-lap timing data |

### Key Relationships

```
races.circuitId        → circuits.circuitId
results.raceId         → races.raceId
results.driverId       → drivers.driverId
results.constructorId  → constructors.constructorId
results.statusId       → status.statusId
qualifying.raceId      → races.raceId
qualifying.driverId    → drivers.driverId
qualifying.constructorId → constructors.constructorId
driver_standings.raceId   → races.raceId
driver_standings.driverId → drivers.driverId
constructor_standings.raceId → races.raceId
constructor_standings.constructorId → constructors.constructorId
```

## Ingestion Methods

### 1. Demo / Quick Start (recommended for first run)

```bash
cd scripts
python ingest_data.py
```

This checks for existing CSV files; if none are found, it generates realistic
sample data covering seasons 2010–2024 and writes it into `data/f1_data.db`.

> ⚠️ Generated data is labeled **"DEMO DATA"**. It uses real circuit, driver,
> and constructor names with realistic results, but is not sourced from the
> official database.

### 2. Fetch from Jolpica-F1 API

```bash
cd scripts
python fetch_api_data.py
```

Downloads all data for seasons 2010–2026 as CSV files in `data/`, then loads
them into SQLite. Respects the API rate limit of 4 req/s.

### 3. Load Existing CSV Files

If you already have Ergast-format CSV files in `data/`:

```bash
cd scripts
python load_csv_to_db.py
```

Validates and imports all CSV files into `data/f1_data.db`.

## Notes

- The database and CSV files are **git-ignored** (see `.gitignore`). Run an
  ingestion script after cloning.
- Points systems changed over the years; the generator accounts for era-correct
  scoring (see `ingest_data.py` for details).
- Sprint race results are included from 2021 onward.
